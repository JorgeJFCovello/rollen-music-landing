# Rollen Music Landing

Static landing page for the artist Rollen, built with Next.js, TypeScript, and Tailwind CSS.

## Quick start

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build static site

```bash
npm run build
```

Static output is written to `/out`.

See [CLAUDE.md](./CLAUDE.md) for project structure details.
